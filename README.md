# Queers & Gears Motorcycle Alliance

Static website for [queersandgears.com](https://queersandgears.com/).

Cloudflare Pages automatically deploys the `main` branch to production. Other
branches receive preview deployments. GitHub Pages is not used.

## Site direction

The visual identity is dark, punk, drippy, and neon gay. Keep new components
high-energy while maintaining readable text, keyboard focus states, responsive
layouts, and reduced-motion support.

Use these motorcycle communities as ongoing content and feature references,
without copying their designs or language:

- [BiXXY Riders of SEMI](https://bixxymc.com/) for values, philosophy, and rider onboarding
- [Border Riders Motorcycle Club](https://www.borderriders.com/) for rides, events, and participation paths
- [Pride Rides](https://www.priderides.org/) for community programming and event visibility
- [Queer Moto Club](https://www.queermotoclub.com/) for direct, identity-first positioning
